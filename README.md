## Scope and evidence standard

- Only **Claude Fable 5.2** attribution is in scope. No silent relabeling of older versions or neighboring models. Attribution means what the linked public source states, not an independent backend audit.
- **Qualified**: opened public source explicitly identifies the required model, publishes the complete original user input (including author replies or accessible linked records), and shows a corresponding result. Public input disclosure does not guarantee a context-free rerun or disclose system instructions.
- **Needs prompt / near-miss**: visible result/demo evidence exists, but exact input, supplied references, attribution, original provenance or deduplication is unresolved. “One prompt” is not the prompt itself. A partial prompt link is never labeled “Copy original”.
- All types belong here: films, animation, games, sliders, websites/UI, 3D, music/notation and other applications. A video attachment of a game remains a game. No qualified entry in a category means only that none was verified yet, not that none exists.
- This is **source verification, not frame-by-frame visual acceptance, independent model reruns, safety/reliability certification or copyright clearance**. Author-reported runtimes, costs, benchmark scores and quality are not audited facts.
- Link to originals; do not download or rehost media. Prompts and results remain subject to their authors’ rights. CC0 applies only to our original list/database contributions, not third-party works.
- All precise timestamps are converted to Asia/Shanghai (UTC+8). Unknown times stay null in JSON. Source-only date labels retain their unspecified timezone; no guessed midnight is created. Hype or code dates use run metadata and are labeled accordingly.
- We never comment or DM authors to unlock prompts. Related-list totals are discovery claims, not verified counts. This is a growing, non-exhaustive list.
